### 2.1 Contagem de Palavras

| Metrica | Valor | Status |

| Conteudo total (apos JS) | ~650 palavras estimadas | ALERTA |
| Minimo recomendado para homepage SaaS | 800-1200 palavras | ABAIXO |

**Nota:** 4/10 — O conteudo principal e renderizado via `"use client"` (FeaturesSection, EmailCampaignsSpotlight, HowItWorksSection, PricingSection). O HTML cru retorna `$RX("B:0","BAILOUT_TO_CLIENT_SIDE_RENDERING")` e `$RX("B:1","BAILOUT_TO_CLIENT_SIDE_RENDERING")`, indicando que o React RSC fez bailout para client-side rendering em partes criticas.

**Impacto SEO:** Googlebot processa JS, mas com atraso. O conteudo renderizado client-side pode:
- Demorar para ser indexado
- Ser parcialmente ignorado em crawl budgets apertados
- Nao aparecer em AI Overviews/SGE que preferem conteudo estatico

**IMPORTANTE:** A secao Hero (H1 + subtitulo + CTAs) e o header sao server-rendered via RSC payload. Os schemas JSON-LD tambem. Porem **FeaturesSection**, **EmailCampaignsSpotlight**, **HowItWorksSection** e **PricingSection** sao todos `"use client"` com framer-motion, forcando client-side rendering.

1. **`product-banner.svg` com 7.7 MB** — Este e o hero image. Um SVG de 7.7 MB e extremamente pesado e impacta diretamente LCP (Largest Contentful Paint). Deve ser otimizado (minificar SVG) ou convertido para WebP/AVIF com < 200 KB.

3. **OG image em PNG (452 KB)** — Funcional, mas poderia ser otimizada para < 200 KB.
4. Nenhuma imagem usa formato next-gen (WebP/AVIF) para raster.
5. O SVG de 7.7 MB esta sendo preloaded via HTTP header `Link: </images/product-banner.svg>; rel=preload; as="image"`, o que piora a situacao ao forcar download imediato.

## 8. Recomendacoes Priorizadas (Quick Wins)

### Semana 1 — Performance e Indexabilidade

1. **Otimizar `product-banner.svg`** — Executar SVGO ou converter para WebP. Meta: < 150 KB. Impacto: LCP melhora 3-5 segundos.

4. **Corrigir acentos no FAQPage schema** — Substituir "e" por "e", "saude" por "saude", etc.

5. **Adicionar links para `/recursos/*` na homepage** — Pelo menos na secao Features ou no footer.
